▲ Commands Worth Knowing

/security-review Audit pending branch changes for security vulnerabilities before shipping client-facing code. Runs a structured review and flags findings with line references.
gh run watch Stream a GitHub Actions workflow run in real time without leaving the terminal. Essential for monitoring automated report pipelines triggered on a schedule.
/resume Re-enter any prior Claude Code session with full context, open files, and tool state intact. Critical for multi-day agent tasks that span working sessions.
bq query Execute a BigQuery SQL query directly from the command line. Fastest way to validate pipeline output without opening the console. Pipe results to jq for quick analysis.
/compact Compress the conversation to reclaim context window space. Use before starting a long agent run — compresses prior turns without losing key facts.
claude --dangerously-skip-permissions Run Claude Code non-interactively for CI/CD pipelines and scheduled automation. Use only in sandboxed environments where all tool calls are pre-authorised.

▲ Analyst Note

An IPO filing changes the game — not for clients, but for the platform. The moment a foundation model provider files an S-1, the API becomes a revenue line on a quarterly earnings call. Experimental pricing ends. Enterprise sales ramps. Roadshow narratives require logos and contract values. The small teams that built their entire operating model on top of one provider's API now have a new counterparty: a public company with shareholder obligations. The structural lesson this week is not about model benchmarks or MCP adoption curves. It is about concentration risk. Any firm that has not yet stress-tested what it costs to run the same workflows on a different model provider — or on open weights — is one pricing announcement away from a margin problem. The moat is client context. The insurance policy is model portability.
