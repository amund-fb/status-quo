▲ Commands Worth Knowing

/resume Resume a previous Claude Code session by PR or task — restores context, file state, and prior tool calls.
/mcp List, add, and manage MCP server connections in Claude Code. Start here when wiring up Slack, BigQuery, or Notion.
slack create agent Scaffold a complete Slack AI agent project with Slack SDK 4.0.0 — generates app manifest, listener boilerplate, and config.
bq query Run a BigQuery SQL query from the terminal. Pair with --format=json and pipe to Claude for instant natural-language analysis.
gh run watch Stream a GitHub Actions CI run live in the terminal — no browser tab required. Exits with the run's status code.
/compact Compress the Claude Code conversation to reclaim context space. Run this before large file reads or multi-step pipelines.
