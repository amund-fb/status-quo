▲ Commands Worth Knowing

/deep-research Fan out a multi-source research sweep with adversarial verification. Runs as a workflow — returns a cited report, not a summary.
/code-review Review the current diff for correctness, simplification, and efficiency. Pass --fix to apply findings directly to the working tree.
/loop Run a prompt or slash command on a recurring schedule (e.g. /loop 10m /review). Keeps a background task running without manual re-triggering.
gh run watch Stream a live GitHub Actions run in your terminal. Useful when you've pushed and want to watch CI without opening the browser.
/security-review Run a full security review on pending branch changes — covers OWASP top 10, injection risks, auth issues, and secrets exposure.
bq query Run a BigQuery SQL query from the CLI: bq query --use_legacy_sql=false 'SELECT ...' — faster than the console for iterating on analytical queries.

They are bids for the context window — the place where your organization's memory, workflow, and decisions live. Whoever owns that context owns the workflow.
