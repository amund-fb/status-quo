▲ Commands Worth Knowing

/compact Compress the current conversation to free up context without losing key facts. Use before long agentic runs hit the window limit.
/resume Pick up your last Claude Code session exactly where you left off — context, files, and in-progress tool state all restored.
/init Generate a CLAUDE.md for your project — persistent context that every Claude session reads on start. One file, zero repeat briefing.
claude -p Run a Claude prompt non-interactively from the terminal. Pipe output to files or downstream commands. Moves to separate billing June 15.
gh run watch Stream live GitHub Actions CI logs to your terminal. Use after a git push to watch the pipeline in real time without opening a browser.
bq query Run BigQuery SQL from the command line. Add --format=json and pipe to Claude Code for inline analysis of query results.
