▲ Commands Worth Knowing

/schedule Create a scheduled remote agent that runs on a cron. The newsletter you're reading was built by one.
/security-review Run a full security audit on the pending changes in your current branch before shipping to production.
/review Run a full code review on the current pull request — correctness, reuse, and efficiency. Pass --fix to auto-apply findings.
gh run watch Stream GitHub Actions CI logs in real time from the terminal. No browser needed to monitor a running deployment.
bq query Run BigQuery SQL from the terminal: bq query --nouse_legacy_sql 'SELECT ...' — pipe results directly into Claude for analysis.
